# AuditFlow

AuditFlow — SaaS para Gestão de Auditorias Internas (esqueleto inicial).

Estrutura monorepo com `frontend/` (React + Vite + MUI) e `backend/` (Flask + MySQL).

Dev rápido com Docker Compose:

```bash
docker compose up --build
```

Este repositório contém o skeleton inicial. Implementações funcionais virão em sprints.
